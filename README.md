# Don't Drink Alone - Mobile App UI Prototype

Neon Dark Theme UI Design for the social drinking app.
HTML5 + CSS3 static prototypes, iPhone 14 Pro (390x844) frame.

## Pages
- `index.html` - UI Showcase Landing (all pages preview)
- `home.html` - 首頁 Home
- `moments.html` - 動態 Moments
- `party.html` - 約酒局 Party
- `messages.html` - 消息 Messages
- `profile.html` - 我的 Profile
- `explore.html` - 探索頁 Explore
- `bar-detail.html` - 酒吧詳情 Bar Detail
- `coin-shop.html` - 幣幣商城 Coin Shop
- `login.html` - 登入頁 Login
- `party-create.html` - 發起酒局 Party Create
- `share-table.html` - 拚桌實況 Share Table
- `publish.html` - 發佈頁 Publish

## Theme
- Neon Dark Theme with CSS variables
- Common styles in `common.css`
- Noto Sans TC (Google Fonts)
