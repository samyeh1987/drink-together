## 不要一個人喝酒 UI 全面重規劃（第二版）

### 需求變更
用戶要求根據新的 TabBar 結構重新規劃 5 個核心頁面：
**首頁 / 動態 / 約酒局 / 消息 / 我的**（動態替換原「探索」tab）

### 重新設計的頁面（保留原霓虹暗黑配色）

#### 首頁 home.html（重寫）
- Banner 自動輪播（3張，JS 自動切換 + 小圓點指示器）
- 快速功能 4 格 icon：賺金幣（金色邊框+角標）、商城（藍色）、約酒局（粉色）、附近酒吧（綠色）
- 今晚的酒局：橫向滑動小卡片（招募中/進行中/已滿狀態）
- 酒友照片牆：九宮格 + 首格大圖（large grid），含用戶名、點讚數

#### 動態 moments.html（全新建立）
- 仿微信朋友圈設計
- 頂部好友 Story Ring（漸層邊框+未讀動態）
- 發文者頭像、姓名、多種標籤（位置/酒吧/氛圍）
- 支援 1/2/3/4 張照片多種排版
- 互動：點讚（toggleLike JS）、留言、分享
- 已有留言顯示在卡片內
- 右下角 FAB 發布按鈕（粉色漸層）

#### 約酒局 party.html（重寫）
- 頂部「我發起的酒局」摘要卡片（金色邊框）
- 子 tabs：推薦/附近/最新/我參加的
- 篩選 chips：全部/今晚/明天/AA制/女生可參加/3人以下
- 酒局卡片：頂部色帶（hot/new/urgent）+ 發起人+桌長徽章 + 狀態 + 標題+描述+標籤+meta+成員頭像+加入按鈕（招募中/已申請/已滿）
- 右下角 FAB 連到 party-create.html

#### 消息 messages.html（重寫）
- 全部/點讚/留言/系統 tab 分類
- 系統消息：特殊金色卡片（金幣獎勵、等級提升）
- 酒局申請通知：接受/拒絕按鈕
- 點讚/留言/關注通知：帶頭像+類型圖示
- 附帶動態預覽/縮略圖
- unread 左側藍色高亮邊條

#### 我的 profile.html（重寫）
- 封面漸層背景 + 右上角設定按鈕
- 大頭貼（含在線綠點）+ 編輯資料按鈕
- 名稱、ID、個人簡介
- 個人標籤 6 個：年齡/星座/位置/身高/體重/生日（各自配色）
- **關注/被關注/被看過** 三格統計，點擊展開人員列表面板（JS toggle）
  - 面板含對應人員頭像、姓名、國籍標籤、關注/回關按鈕
- 等級卡片（進度條 68%）
- 功能選單：金幣、訂單、酒局紀錄、動態、設定
