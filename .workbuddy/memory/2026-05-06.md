# 2026-05-06

## 不要一個人喝酒 UI 重構 - 新增核心功能頁面

### 架構調整
- **TabBar 重新規劃**：從 5 tabs（含中央發佈按鈕）改為 5 均等 tabs：首頁/探索/約酒局/消息/我的
- 移除中央發佈按鈕（發佈功能改為首頁 header 入口）
- 新增「約酒局」tab 作為核心差異化功能，使用金色霓虹（neon-yellow）作為 tab 強調色
- `common.css` 中新增 `.party-tab` 和 `.party-badge` 樣式（含綠色呼吸燈效果）

### 新增頁面（3個）
1. **party.html** — 約酒局首頁（TabBar 核心頁）
   - 4 個子 tabs：推薦/附近/拚桌實況/我的酒局
   - 拚桌實況 LIVE Banner（綠色呼吸燈 + 橫向滑動小卡）
   - 酒局卡片：發起人頭像+姓名+組織次數、標題、描述、氛圍標籤、時間/距離/費用、加入人數、加入按鈕
   - 3 種卡片頂部色帶：hot(粉橙)/new(藍綠)/urgent(黃橙)
   - 右下角浮動 FAB 按鈕（金色漸層）用於快速發起酒局
2. **party-create.html** — 發起酒局表單
   - 標題輸入、描述文本框
   - 酒吧選擇器（已選狀態展示）
   - 日期/時間選擇器（雙列）
   - 人數限制控制（+- 按鈕）
   - 費用模式三選一：AA制/我請客/分攤
   - 參加限制四選一：不限/限男生/限女生/男女各半
   - 氣氛標籤多選（16種）
   - 金色漸層提交按鈕
3. **share-table.html** — 酒吧拚桌詳情
   - 酒吧資訊卡（封面、名稱、類型、地址、評分、營業狀態、營業時間、距離、人均消費）
   - 桌長名片（頭像、姓名、國旗、桌長徽章、個人簡介、組織次數、好評率、私信按鈕）
   - 桌長留言（引號樣式）
   - 已加入成員列表（含在線狀態、桌長標籤、等待加入占位）
   - 申請加入 CTA（金色邊框卡片、雙按鈕：申請加入/先聊聊）
   - 拚桌須知（4條規則）
   - 附近其他拚桌推薦
