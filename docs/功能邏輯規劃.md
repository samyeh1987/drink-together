# 不要一個人喝酒 — 功能邏輯規劃

> 版本：v1.2 | 更新：2026-05-09  
> 架構：H5 Web App（Supabase 後端 + Vercel 前端）  
> 語言支援：簡體中文 / English / ภาษาไทย

## 一、用戶系統

### 1.1 註冊 / 登入

| 方式 | 說明 |
|------|------|
| 手機號碼 + OTP | 泰國 (+66) 為主，支援台灣 (+886) / 馬來西亞 (+60) |
| LINE 快速登入 | 東南亞主流，優先支援 |
| Google 登入 | 外籍旅客備選 |

**登入後跳轉**：若首次登入 → 引導填寫個人資料頁 → 首頁；否則直接進首頁。

### 1.2 個人資料

必填：暱稱、性別、**年齡（自填，須為 18 歲以上）**  
選填：頭像、自我介紹、國籍、星座、身高、體重  
標籤：可選最多 5 個興趣標籤（爵士、威士忌、電音、桌遊、串燒…）

**年齡驗證規則**（✅ 已確認）：
- 採用「用戶自填年齡」方式，不要求上傳證件
- 填寫年齡時顯示提醒文字：「本平台僅限 18 歲以上成年人使用，請遵守當地未成年人禁止飲酒的相關法規」
- 填寫未滿 18 歲將無法完成註冊
- 免責聲明：平台不負責核實年齡真實性，責任由用戶自行承擔

### 1.3 用戶等級制度（✅ 已確認）

> ✅ Lv.2 才能發起酒局

| 等級 | 名稱 | 升級條件 | 解鎖權限 |
|------|------|---------|---------|
| Lv.1 | 🌱 新手酒友 | 完成註冊 | 瀏覽酒局、申請加入、發動態 |
| Lv.2 | 🍺 入門喝客 | 累計**參加 3 場**酒局（桌長確認簽到） | **發起酒局**、邀請好友 |
| Lv.3 | 🥃 熟客酒鬼 | 累計參加 **10 場** + 發動態 **5 則** | 酒局加精選推薦排序加成 |
| Lv.4 | 🎉 派對達人 | 累計參加 **25 場** + 發起酒局 **3 次** + 平均評分 ≥ 4.2 | 個人主頁「達人認證」徽章、優先排序 |
| Lv.5 | 🏆 傳奇酒神 | 累計參加 **50 場** + 被評為桌長推薦 **10 次** + 帳號存在 ≥ 90 天 | 限定頭像框、「傳奇」專屬標籤、後台合作洽談資格 |

**等級補充規則**：
- 等級只升不降（即使後來參加場次減少）
- 每次升級觸發系統通知 + 金幣獎勵（見下方金幣任務表）
- 等級計算基準：桌長**確認入座**才算，申請中/被拒絕不計入

### 1.4 用戶安全 & 內容管理（✅ 已確認）

#### 違規處罰機制

> 前期採人工審核，以下為執行框架：

| 違規程度 | 觸發條件 | 處罰 |
|---------|---------|------|
| 輕微 | 首次被舉報，審核認定輕微違規 | 警告通知，保留功能 |
| 中等 | 累計 3 次違規 / 審核認定中等違規 | 限制部分功能 7 天（不可發動態、不可發起酒局） |
| 嚴重 | 累計 5 次違規 / 一次嚴重違規（性騷擾、詐騙、散佈不雅內容） | 永久封號 |

**被多次封鎖 / 舉報的限制規則**：
- 被不同用戶封鎖累計達 **10 次** → 系統自動標記為「待審核帳號」，人工確認後決定處罰
- 被舉報累計達 **5 次**且審核通過 → 觸發功能限制
- 限制期間帳號仍可登入瀏覽，但無法：發動態、發起酒局、申請加入酒局、發私信

**動態圖片審核**：
- 前期採純舉報機制（用戶按「舉報」→ 平台人工審核）
- 不接入 AI 審圖（前期成本控制）
- 後續業務擴大後再評估是否引入 Google Vision / AWS Rekognition

## 二、金幣系統 🪙

> ✅ 金幣無有效期，永久有效

### 2.1 金幣獲取

#### A. 酒吧人員手動發放（核心機制）
- 酒吧方有後台，可對到訪用戶掃描用戶 QR Code 手動發幣
- 用途：消費滿額獎勵、活動參與、特殊任務完成
- 發放金額由酒吧自訂（通常 50～500 幣/次）
- 每位用戶在同一酒吧同一天**最多被發放 3 次**（防刷）
- 酒吧手動發放**不計入用戶每日金幣上限**（商業發放另計）

#### B. 系統自動任務（App 內賺幣）

| 任務 | 金幣 | 頻率 |
|------|------|------|
| 完成個人資料（頭像+簡介+3個標籤）| +200 | 一次性 |
| 首次參加酒局 | +100 | 一次性 |
| 升級至 Lv.2 | +100 | 一次性 |
| 升級至 Lv.3 | +200 | 一次性 |
| 升級至 Lv.4 | +500 | 一次性 |
| 升級至 Lv.5 | +1000 | 一次性 |
| 邀請好友加入（好友完成首次參加酒局）| +150/人 | 無上限 |
| 每日登入簽到 | +10 | 每日 |
| 連續 7 天登入 | 額外 +50 | 每週重置 |
| 發布動態（含照片）| +20 | 每日上限 3 次 |
| 動態獲得 10 個讚 | +30 | 每篇一次 |
| 發起酒局（成功開桌，至少 2 人入座）| +50 | 每場一次 |
| 參加酒局（桌長確認簽到）| +30 | 每場一次 |
| 完成酒局後為桌長評分 | +10 | 每場一次 |
| 酒吧簽到 | +5 | 每日每家酒吧 1 次 |

#### C. 活動限時任務（後台設定）
- 酒吧可在後台發布限時任務（如「本週五到場打卡 +200 幣」）
- 首頁 Banner 和「賺金幣」頁展示當前活動任務
- 平台也可發布全域活動（如節慶期間 2 倍金幣）

### 2.2 每日金幣上限規則（✅ 已確認）

> 目的：防止刷號、保護金幣系統平衡

| 類型 | 每日上限 |
|------|---------|
| 系統任務賺取（含簽到、動態、酒局任務）| **上限 300 幣/天** |
| 酒吧手動發放 | **不計入上限**（屬商業行為，酒吧自行控制） |
| 活動限時任務 | **不計入上限**（屬促銷行為，後台設定上限） |

**補充說明**：
- 一次性任務（完成資料、首次參加、升級獎勵）不受每日上限限制
- 邀請好友獎勵不受每日上限限制（防作弊由邀請規則控制）
- 每日 0 點（GMT+7）重置計數

### 2.3 金幣消費（幣幣商城）

| 商品類型 | 範例 | 幣值參考 |
|---------|------|---------|
| 🍜 餐廳套餐 | 泰式料理雙人套餐 | 500 幣 |
| 🎤 KTV | 歡唱 3 小時包廂 | 300 幣 |
| 🍸 酒吧體驗 | 免費調酒 1 杯 | 150 幣 |
| 💆 SPA | 泰式按摩 60 分鐘 | 200 幣 |
| 🎮 娛樂 | 桌遊包廂 2 小時 | 180 幣 |

**兌換流程**：
1. 點「兌換」→ 確認視窗（顯示商品名稱、所需金幣、現有餘額）
2. 確認後 → 扣除金幣 → 產生電子券（含 QR Code + 有效期限）
3. 到店出示 QR Code → 商家後台掃碼核銷 → 電子券失效

### 2.4 金幣規則（✅ 已確認）

- 金幣**無法轉讓**給其他用戶
- 金幣無現金價值，**不可提現**
- 金幣**永久有效**，無到期日
- 電子券有效期限 **30 天**，逾期失效（金幣**不退回**，金幣屬店家贈送）
- 兌換後**不支持取消或退幣**，請確認後再兌換
- **商品下架後**：已兌換的電子券仍有效；若商家申請下架並有未核銷的券，**後台可手動退還金幣**給用戶

## 三、酒局系統 🍻

### 3.1 發起酒局

> ✅ Lv.2 以上才能發起  
> ✅ 桌長不可轉讓

**發起條件**：
- 等級 Lv.2 以上
- 頭像已上傳
- 手機號已驗證

**必填欄位**：
- 酒局標題（最多 20 字）
- 日期時間（不得早於現在 30 分鐘）
- 地點（搜尋酒吧庫 或 手動輸入地址）
- **人數範圍**（如「3～8 人」，系統申請超過上限自動關閉；到達下限即可開始）
- 費用方式（AA 制 / 桌長請客 / 各自付）
- 性別限制（不限 / 女生可參加 / 限女 / 限男）

**選填**：標籤（最多 5 個）、酒局描述（最多 200 字）、封面圖片

**同時發起上限**：每位用戶最多同時有 **3 場招募中**的酒局

**桌長轉讓**：❌ 不支援。桌長如需取消，直接取消酒局。

### 3.2 人數規則（✅ 已確認）

- 發起時可設定**人數範圍**（最小值～最大值），例如「3～8 人」
- **申請人數達到下限（最小值）即可手動開始酒局**
- **申請人數超過上限（最大值）自動關閉報名**
- 建議下限最少 2 人（桌長 + 至少 1 位成員）

### 3.3 參加酒局

**申請流程**：
1. 點「加入」→ 系統檢查人數是否已滿
2. 送出申請 → 通知桌長（消息頁面）
3. 桌長接受 → 用戶收到「已接受」通知 → 正式入局
4. 桌長拒絕 → 用戶收到「申請未通過」通知

**申請條件**：
- 用戶頭像已上傳
- 帳號已驗證手機號
- 未被桌長封鎖

**等待確認時間**：桌長須在 **6 小時內**回應，超時系統自動取消申請

**同一酒局申請次數上限**（✅ 已確認）：
- 同一用戶對同一場酒局**最多申請 2 次**
- 第 1 次被拒後可再申請 1 次；第 2 次被拒則不得再申請

### 3.4 退出酒局 & 信用分規則（✅ 已確認）

> 退出酒局會扣除信用分，信用分影響酒局排序可見度

| 退出情境 | 信用分扣除 | 說明 |
|---------|-----------|------|
| 酒局開始前 **24 小時以上**退出 | -1 分 | 提前告知，影響較小 |
| 酒局開始前 **6～24 小時**退出 | -3 分 | 桌長難以補人 |
| 酒局開始前 **6 小時內**退出 | -5 分 | 嚴重影響酒局進行 |
| 酒局開始後**無故缺席**（桌長標記）| -8 分 | 最嚴重，已影響其他人 |
| 正當原因退出（附說明，桌長確認）| 0 分 | 如突發緊急事故 |

**信用分規則**：
- 初始信用分：**100 分**
- 信用分區間與影響：

| 信用分 | 狀態 | 影響 |
|--------|------|------|
| 80～100 | 🟢 優質用戶 | 正常顯示，可能有優先排序加成 |
| 60～79 | 🟡 普通用戶 | 正常使用，無加成 |
| 40～59 | 🟠 警告用戶 | 酒局申請被桌長接受率可能降低 |
| 20～39 | 🔴 高風險用戶 | 系統提示桌長「此用戶信用偏低」 |
| 0～19 | ⛔ 限制用戶 | 無法發起酒局；申請酒局需等待桌長額外確認 |

**信用分恢復**：
- 每成功完成一場酒局（桌長確認到場）+2 分
- 每月最多恢復 10 分（自然恢復上限）
- 信用分上限 100 分，不可超過

### 3.5 酒局狀態流轉

```
草稿 → 招募中 → 進行中 → 已結束
              ↓
           已取消（桌長主動取消 / 到開始時間仍 0 人 → 系統自動取消）
```

- **招募中**：開放申請，顯示於列表
- **進行中**：開始時間到 → 自動切換（或桌長手動開始）
- **已結束**：結束時間到 / 桌長手動結束 → 觸發評分
- **取消規則**：開始前 2 小時內取消 → 已入局成員收到通知

### 3.6 酒局評分

- 酒局結束後 **24 小時內**可評分
- 評分項目：⭐ 氛圍（1-5） / ⭐ 桌長組織力（1-5） / ⭐ 整體滿意度（1-5）
- 評分後雙方各得 **+10 幣**
- 累積好評影響桌長**信用分**（影響酒局推薦排序）
- 低信用分（信用分 < 60）桌長的酒局降低曝光

## 四、私信 / 消息系統 💬

### 4.1 通知（Notification）— 單向系統消息

所有用戶都能收到，無門檻：

| 類型 | 觸發條件 |
|------|---------|
| 點讚通知 | 有人讚了你的動態 |
| 留言通知 | 有人留言了你的動態 |
| 關注通知 | 有人關注了你 |
| 酒局申請 | 有人申請加入你的酒局 |
| 酒局審核結果 | 你的申請被接受/拒絕 |
| 酒局即將開始 | 已入局的酒局距開始 1 小時提醒 |
| 系統消息 | 金幣獎勵、等級提升、活動通知 |

### 4.2 私信 — 有門檻的雙向對話

> ✅ 滿足以下**任一條件**即可發私信：
> - 雙方**互相關注**
> - 曾在**同一場酒局**同桌（桌長確認入座）

**目的**：防止陌生騷擾，保護女性用戶安全

**私信功能**：
- 文字訊息（最多 500 字/則）
- 表情符號 / emoji
- 傳送酒局邀請（卡片形式）
- 傳送商城商品（推薦分享）
- 圖片傳送（最多 9 張/次）

**私信顯示規則**（✅ 已確認）：
- ❌ 不顯示「已讀」回執
- ❌ 不提供「被看過」統計關閉選項（即：不顯示誰看了你的個人頁面）

**封鎖功能**：
- 任何人可封鎖任何用戶
- 封鎖後：對方無法查看你的動態、無法私信你、無法申請你的酒局
- 封鎖不會通知對方

### 4.3 私信留存規則（✅ 已確認）

- **後端**：永久保留私信紀錄
- **客戶端（App 顯示）**：保留最近 **180 天**的對話記錄
- 超過 180 天的訊息客戶端不加載，但後端可依需求查詢（如客服、法律需求）

### 4.4 關注規則（✅ 已確認）

- 取消關注 **不通知**對方
- 單向關注（類似 IG / 微博）
- 互相關注 = 好友（解鎖私信功能）

## 五、動態系統 📸

### 5.1 發布動態

> ✅ 預設可見範圍：**公開**（用戶可手動改為「只限好友」）  
> ✅ 支援泰文發動態

**可發內容**：
- 文字（最多 500 字，支援中/英/泰文輸入）
- 圖片（最多 9 張，單張上限 10MB）
- 地點標記（選填）
- 酒吧標記（選填，從已收錄酒吧搜尋）
- 心情標籤（微醺 / 嗨翻 / 清醒喝酒 / 放鬆…）

**可見範圍選項**：
- 🌍 公開（所有人，預設）
- 👥 只限好友（互相關注）
- 🍻 只限同桌酒友

### 5.2 動態互動

| 互動 | 門檻 |
|------|------|
| 點讚 ❤️ | 任何人（含非好友）|
| 留言 💬 | 任何人（含非好友）|
| 分享 | 分享到私信（需符合私信條件）或複製連結 |
| 舉報 | 任何人，需填舉報原因 |

### 5.3 動態推薦演算法

動態 Feed 及首頁酒局排序依據：
1. **關注者動態**優先（你關注的人）
2. **地理位置**（曼谷市區優先）
3. **時間新鮮度**（今天 > 昨天 > 更早）
4. **互動熱度**（讚 + 留言數加權）

## 六、酒吧 / 探索系統 📍

### 6.1 酒吧資料維護（✅ 已確認）

> ✅ 由**平台人工建檔**

每個酒吧包含：
- 基本資訊：名稱（參照 Google Map 顯示，無需三語）、地址、分類（爵士吧 / 酒吧 / KTV / 夜店…）
- 營業時間、最低消費
- 圖片（最多 20 張）
- 平均評分（來自用戶評分，✅ 已開放）
- 目前在場用戶數（real-time 簽到統計）
- 本週活動列表

### 6.2 酒吧評分（✅ 已開放）

- 用戶可對到訪酒吧（簽到後）進行評分
- 評分項目：⭐ 環境（1-5） / ⭐ 服務（1-5） / ⭐ 性價比（1-5） + 文字評論
- 評分顯示：酒吧詳情頁展示平均分及評論列表
- 防刷：同一用戶同一酒吧 **7 天內**只能評分 1 次

### 6.3 酒吧簽到

> ✅ 簽到距離：500 公尺

- 用戶在酒吧 **500 公尺內**可點「簽到」
- 簽到後出現在「目前在場」列表（可選擇隱藏）
- 每家酒吧每天簽到一次，獲得 **+5 幣**
- 簽到可觸發酒吧額外發放金幣（酒吧方設定）
- 離開酒吧後 3 小時自動「離場」

### 6.4 地理範圍規劃（✅ 已確認）

| 城市 | 狀態 |
|------|------|
| 曼谷 | Phase 1 正式上線 |
| 吉隆坡 | 隨時可展開，無固定時間點 |

- 新城市展開只需在後台新增城市、建檔酒吧，系統架構已支援多城市

### 6.5 酒吧後台功能（B 端）

| 功能 | 說明 |
|------|------|

## 八、多語言支援

> ✅ 支援：簡體中文 / English / ภาษาไทย

- 預設語言：根據手機系統語言自動偵測
- 用戶可在「設定 → 語言」手動切換
- **酒吧名稱**：參照 Google Map 顯示，不需三語版本
- **商品名稱**：後台填寫時直接提供中文 + 英文版本
- **用戶生成內容**（動態、酒局描述）：不翻譯，維持原文；✅ 支援泰文輸入
- **系統介面 & 通知文字**：提供三語版本

## 九、通知 & 推播系統

> ✅ 已確認：Email 通知 ✅ | LINE 通知 ❌（暫不接入）

### 9.1 In-App 通知（消息 Tab）
- 所有用戶事件通知均在 App 內消息頁顯示
- 未讀紅點提醒

### 9.2 Web Push Notification（H5 階段）

> 建議接入（成本低，效果好）

- H5 階段使用瀏覽器原生 **Web Push API**（免費，基於 Service Worker）
- 用戶首次登入後詢問是否允許推播通知
- 推送場景：酒局申請通知、酒局即將開始（1 小時前）、系統金幣獎勵
- 轉 App 後直接改用 FCM（Firebase Cloud Messaging），邏輯一致

### 9.3 Email 通知

> ✅ 接入 Email 通知

| 觸發事件 | 郵件內容 |
|---------|---------|
| 成功註冊 | 歡迎郵件 + 新手指引 |
| 酒局申請被接受 | 酒局詳情 + 加入時間提醒 |
| 酒局即將開始（1 小時前）| 酒局地址 + 開始時間 |
| 等級提升 | 恭喜郵件 + 新解鎖功能說明 |
| 金幣重大異動 | 大額金幣扣除或獲取提醒（防帳號被盜）|

- 推薦使用 **Resend** 或 **SendGrid**（與 Supabase 整合方便）
- 用戶可在設定中**關閉 Email 通知**
